# Rubik & Groupes

Cours illustré de théorie des groupes, niveau maths sup et maths spé.

Avec Python 3.10 ou plus récent, lancer `python rubik_groupes.py` depuis ce dossier.
Sous Windows, on peut aussi ouvrir `Lancer_Rubik.cmd`.

Le laboratoire s’ouvre dans le navigateur à l’adresse http://127.0.0.1:8765.

Voir également le [premier parcours](../PREMIER-PARCOURS.md).
