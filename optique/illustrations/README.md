# Figures d’optique

Les **24 figures scientifiques originales** relient une scène calculée à une
courbe de contrôle. Chaque fichier SVG peut être ouvert indépendamment dans
un navigateur et projeté pour accompagner un cours.

Les légendes précisent les unités, les conventions et les approximations.
Une figure d’intensité peut afficher √I pour rendre les anneaux ou lobes
visibles ; la courbe quantitative conserve I. Les schémas des résonateurs
indiquent les trajets multiples sans prétendre dessiner le champ complet.

Les figures correspondent aux paramètres par défaut du laboratoire ; les TP
permettent de les modifier et d’exporter les données obtenues.

Pour les régénérer depuis le dossier `optique` :

```text
python -m pip install -r requirements-illustrations.txt
python -X utf8 optique.py --export-illustrations
```
